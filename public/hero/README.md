# Hero Background Images

## Как добавить фотографии

1. Поместите ваши фотографии в эту папку (`/public/hero/`)
2. Назовите их последовательно:
   - `hero-1.jpg`
   - `hero-2.jpg`
   - `hero-3.jpg`
   - `hero-4.jpg`
   - `hero-5.jpg`
   - `hero-6.jpg`

## Рекомендации по фотографиям

- **Формат**: JPG или PNG
- **Размер**: Рекомендуется 1920x1080px или больше
- **Качество**: Высокое разрешение для четкости на больших экранах
- **Ориентация**: Горизонтальная (ландшафтная)
- **Тематика**: Фотографии вашей команды, роботов, соревнований, процесса работы

## Настройка

Если вы хотите изменить:
- **Количество фотографий**: Отредактируйте массив `heroImages` в `src/app/(public)/page.tsx`
- **Интервал смены**: Измените параметр `interval` (в миллисекундах) в компоненте `HeroBackgroundSlider`
  - Например: `interval={20000}` для 20 секунд

## Пример

```tsx
const heroImages = [
  "/hero/hero-1.jpg",
  "/hero/hero-2.jpg",
  "/hero/hero-3.jpg",
  // Добавьте или удалите строки по необходимости
];
```

## Текущий интервал

- 15 секунд между фотографиями
- Плавный переход (fade) 1.5 секунды
